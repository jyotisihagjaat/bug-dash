# 🐞 Bug Dash

A fast-paced browser game where you play a developer trying to ship clean code. Catch the coffee, dodge the bugs, and see how long you can survive.

### 🎮 [Play it now](https://jyotisihagjaat.github.io/bug-dash)

)

## How to play

- Catch falling coffee ☕ to score a point.
- Dodge the bugs 🐞. Each bug that hits you costs a life.
- You have 3 lives. When they are gone, the build fails.
- The game speeds up as your score grows, so stay sharp.
- Your best score is saved in your browser.

## Controls

| Device  | Control                              |
| ------- | ------------------------------------ |
| Desktop | Left / Right arrow keys, or A / D    |
| Mobile  | Drag your finger across the screen   |

## Built with

- HTML5 Canvas for rendering
- Vanilla JavaScript (no frameworks, no libraries)
- CSS for the layout and styling
- GitHub Pages for hosting

## Run it locally

```bash
git clone https://github.com/YOUR-USERNAME/bug-dash.git
cd bug-dash
```

Then open `index.html` in any browser. No install or build step needed.

## What I learned

- Building a game loop with `requestAnimationFrame`
- Handling keyboard, mouse and touch input in one game
- Increasing difficulty gradually as the score grows
- Saving data in the browser with `localStorage`
- Deploying a project for free with GitHub Pages
